ICONS DIRECTORY — VoltTrail
===========================

Add the following icon files to this directory before deploying:

  icon-16.png   — 16×16px  favicon
  icon-32.png   — 32×32px  favicon
  icon-192.png  — 192×192px  Android home screen / PWA
  icon-512.png  — 512×512px  Splash screen / PWA

All icons should use:
  Background colour: #0a0c0a (dark)
  Icon:              ⚡ lightning bolt in #aaff00 (volt green)

ALSO NEEDED in /public root:
  og-image.jpg  — 1200×630px Open Graph image for social sharing
                  Design: VoltTrail logo + hero bike on dark background

You can generate these at:
  https://favicon.io  (icons)
  https://www.canva.com  (OG image)
  https://realfavicongenerator.net  (full favicon package)
